# HAVEN — Premium Digital Studio

A modern, premium website for HAVEN web development studio built with HTML, CSS, and vanilla JavaScript featuring cinematic animations and sophisticated interactions.

## 🎯 Overview

HAVEN is a freelance digital studio creating modern websites and digital experiences for businesses, brands, creators and startups. This website showcases professional web development capabilities through premium design, smooth animations, and excellent user experience.

## ✨ Features

### Design
- **Premium Black + Purple Theme** - Sophisticated dark design with purple accents
- **Cinematic Animations** - GSAP-powered scroll animations and page transitions
- **Custom Cursor** - Interactive cursor for desktop users with hover states
- **Responsive Design** - Fully responsive across all devices (360px to 1440px+)
- **Visual Depth** - Subtle gradient backgrounds reducing excessive black
- **Editorial Typography** - Large, bold typography with smooth reveals

### Functionality
- **Dynamic Filtering** - Working template and work portfolio filters
- **Contact Form** - Validated contact form with error states
- **Mobile Navigation** - Smooth mobile menu with staggered animations
- **Scroll Progress** - Visual scroll indicator
- **Page Transitions** - Smooth transitions between pages (desktop)
- **Loading Screen** - Premium intro animation with fallback

### Performance
- **Mobile Optimized** - Lighter animations and simplified effects on mobile
- **Fast Loading** - Optimized assets and efficient code
- **Accessibility** - Semantic HTML, ARIA labels, keyboard navigation
- **SEO Optimized** - Proper meta tags, headings, and structure
- **Reduced Motion Support** - Respects user motion preferences
