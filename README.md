# HAVEN — Premium Freelance Digital Studio

A modern, professional website for a freelance web development studio built with HTML, CSS, and JavaScript featuring premium animations and interactions.

## 🚀 Features

- **Premium Design**: Clean, modern interface with purple/black color scheme
- **Smooth Animations**: GSAP-powered animations and scroll effects
- **Custom Cursor**: Interactive cursor for desktop users
- **Responsive Design**: Fully responsive across all devices
- **Page Transitions**: Smooth navigation between pages
- **Template System**: Filterable template showcase
- **Contact Form**: Validated contact form ready for integration
- **SEO Optimized**: Proper meta tags and semantic HTML
- **Accessibility**: WCAG compliant with keyboard navigation
- **Performance**: Optimized for fast loading
