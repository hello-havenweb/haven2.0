HOW TO CREATE THE IMAGE:

  1. Take a screenshot of the canvas above at exactly 1200×630px
  2. Save as og-image.jpg or og-image.png
  3. Place in the root directory of your HAVEN project
  4. Add this meta tag to all HTML pages:

<meta property="og:image" content="https://haven.pntr.dev/og-image.jpg">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta name="twitter:card" content="summary_large_image">
